# zpack GUI 设计 v1（2026-11-21 定稿）

> 先设计后编码（用户定案）。本文是 `ui/gui/` 的唯一权威设计——编码实现以本文为准，实现偏差回改本文。
> 架构铁律不变（ui/doc.go）：GUI 是「厚 UX、薄引擎」——**一切数据经 `bin/zpack` stdout JSON 契约**，引擎层零感知 GUI 存在。

## 0. 三形态一张脸

| 形态 | 入口 | 职责 | 优先级 |
|---|---|---|---|
| **主窗口**（完整 GUI） | 启动 zpack-ui / 打开归档文件 | 归档管理器：压缩台 + 归档浏览器 + 处理台 + 设置 | M1 |
| **Dock 拖放** | 拖文件到 Dock 图标 | 无窗口直达压缩流程（弹压缩对话） | M3 |
| **桌面悬浮窗**（压缩箱） | 主窗口内开关 / 记忆恢复 | 常驻小窗，拖入即压，点击展开迷你任务列表 | M3 |

菜单栏常驻**不做**（用户定案排除）；右键 FinderSync 已独立交付（`ui/right-click/`），与 GUI 互不依赖。

## 1. 主窗口

### 1.1 布局骨架（单窗口多页，左侧窄栏导航；v3 修订：DeepSeek harness 侧栏 + 编辑式内容）

```
┌────────┬────────────────────────────────────────┐
│ Z zpack │  （无 Header——内容从窗口顶直接流下）      │
│ 归档    │  空态=垂直居中 hero（标题+副文案+按钮）    │
│  ▣压缩台│  有选=清单即主角（汇总行+卡片列表+参数+CTA）│

│  处理台│                                        │
│        │                                        │
│ ⚙设置   │                                        │
```

- **右半边 head（v4 定案，覆盖 v2「无标题带」）**：内容区顶部页面标题条
  （`pageTitle()`，15 Bold，与侧栏导航同名，整条 `DragWindow`）——Win/Linux
  关闭钮落在内容区右缘，标题条高度盖住按钮带（`max(bar.Height+16,56)`）且
  右缘让位（`Padding(0,bar.Right,0,contentPadX)`）；macOS 无右钮，标题条纯做
  视觉锚点（高 52）
- **引导行（v4 定案）**：清单头行=状态句「已准备压缩归档 N 项 · SIZE，可继续
  拖动或点击」+整句描边按钮「浏览选择…」（v4 定案：文案与空态 hero 按钮完全一致，带三点省略号；ButtonBase pill，Accent 字，hover 浅底+描边变蓝，点击弹 Finder 选择框 `browseFiles()`）；空态 hero 的「浏览选择…」按钮同走 `browseFiles()`
- **侧栏 DeepSeek harness 布局（v3 定案，用户点名）**：整条稍深色恒不透明
  （浅色 `railLight=#ECEFF3` / 深色 `railDark=#1B2230`——深色模式栏底比内容区
  浅一档）；**选中态=深蓝胶囊+白字白图标**（浅 `#376DB5` / 深 `#2B568C`，角标
  反白；2026-11-21 用户定案，覆盖先前「浅色胶囊」）；自定义 `navItem`
  （ButtonBase 行）而非 `ui.Sidebar`（其灰 pill 违背定案）。分区小标 11pt 弱化；
  品牌 Z 19px（用户定案小一号）
- **编辑式内容排版（v3 定案）**：`contentPadX=28` 左右呼吸（v4 减半——56 太空）/ 底部收紧 16（教训：mygo `edges()`
  是 CSS 序，`Padding(0,40,0,0)` 语义成了「右 40 左 0」致标题贴死侧栏）；
  空态页（compress 无选 / archive / tasks 无任务）走 `Grow(1)+Justify(Center)`
  垂直居中 hero；非空态才包 Scroll
- **品牌行对齐（v3 调优，用户定案）**：Z + 字标左缩进 20（与导航图标列对齐），
  品牌行到首分组间距收紧（Box 4 + 分组头 margin-top 8）
- **参数工具行自适应（v3 定案）**：`Wrap()` 换行——最窄窗宽 720 下「加密」文字+
  开关打包为原子子行整体换行（不拆散、不溢出右内边距）
- **窗口控制钮动态让位（v2 定案）**：每帧读 `ui.Context.TitleBar()`——
  `bar.Left>0`（macOS 红绿灯/Linux 左布局）→ 侧栏顶部让到 `bar.Bottom` 之下；
  `bar.Right>0`（Windows/Linux 右布局）→ 内容区顶部让出 `bar.Height` 拖拽条并给
  右侧 `bar.Right` 让位；全屏（全零）两侧都不让。Linux 桌面按钮布局动态变化自动跟随
- 侧栏结构（m06456 定案 视频/音频/图片独立分组）：**归档**（压缩台/解压台/
  刻录光盘/归档浏览）+ **视频**（视频转换/视频压缩）+ **音频**（音频转换/
  音频压缩）+ **图片**（图片转换/图片压缩/新建图片）+ **文档**（PDF 合并/
  PDF 提取页/Office 转换/PDF 旋转/页面尺寸）+ **加密与编码**（生成密钥/加密/

  紧贴到固定按钮顶上；顶部品牌行（双色 Z + 字标）。
  ~~引擎状态脚注~~ 已移除（2026-11-21 用户定案——「什么引擎？」指向不明，无信息价值）
- **品牌水印（v3 定案：常驻，2026-11-21 用户定案）**：右下 Z 230px、透明度 0.06、
  贴角溢出 `Right/Bottom(-36)`，**所有页面恒显**（垫在内容层下绘制，不扰阅读）；
  初版仅空态显、v2 的 300px/0.07 视觉过重均已废弃
- 深浅色跟随系统；字体全平台内嵌统一：正文=MiSans W450（VF 实例化钉 wght=450——VF 裸注册缺省实例 330 偏细，500 Medium 太粗被否决，400 回退后用户定格 450）；正文/辅助色走文字 Token（main.go colText* 唯一定义点，页面代码只许 t.Text/t.TextMuted 引用）：正文 #3f3f46（浅）/#e4e4e7（深）——用户裁定不要纯黑；辅助解释行（hint/placeholder）=macOS secondaryLabelColor 逻辑（同基色调 60% α：浅色基 #3C3C43@60% 白底合成 ≈#8A8A8E、深色基 #EBEBF5@60%）——m08153 用户裁定解释行要比正文明显浅一档；标题 Bold=MiSans VF 族插值到 700；等宽=JetBrains Mono

### 1.2 页面一：压缩台（默认首页）

```
┌────────────────────────────────────────┐
│        ┌──────────────────────┐        │
│        │   拖入文件或文件夹      │        │
│        │   （或点击选择）        │        │
│        └──────────────────────┘        │
│ 已选列表：                              │
│   📁 项目备份/        128 MB   ✕        │
│   📄 清单.xlsx        2.1 MB   ✕        │
│ ──────────────────────────────         │
│ 格式 [ZIP ▾]  压缩级别 [6 ▾]            │
│ □ 分卷 [模板/大小]  □ 密码 [____]       │
│ 排除：[.zpackignore 自动生效]           │
│            [ 创建压缩包 ]                 │
└────────────────────────────────────────┘
```

- 拖入 = 文件+目录混选；已选列表可增删
- **已选清单形态（v3 定案，2026-11-21 用户定案）**：**单卡片列表**（整卡
  `Radius(10)` 白底描边，行间 1px 分隔线）而非一条条独立卡；每行=图标+
  **完整路径**（只显名不够——来源目录不同时路径才是身份；超长自动换行，
  不截断）+等宽尺寸+✕
- **移除钮（2026-11-21 用户定案）**：**减号图标**（语义=移出清单，非删除文件），平时安静（无底无边、灰），
  **零空间占用**（用户定案）：减号 `Absolute().Right(0)` 叠加在尾槽（Row Shrink+Height 24，槽宽=尺寸数字宽）上层、不进布局——静默态行右侧无空档；行 hover 时尺寸数字淡出、减号右 5px 滑入浮现（110ms 同槽交叉淡换，槽宽恒定不跳）；浮现后 hover 红底白杠（`t.Danger`）+ 白杠放大 15% + 按下沉降 1px；全程 Animate 过渡；光标 pointer。
  此前版本用文本 "✕" 字形缺字渲染成空方块＝用户以为没有删除功能
  （教训：**图标一律走 SVG `icon()`，不用特殊 Unicode 字形**）
- 所有可点元素（导航行/✕/浏览选择/CTA/取消）一律 `Cursor(ui.CursorPointer)`
  （mygo 框架不默认给 Button/PrimaryButton pointer）
- 拖入路径入列前剥尾斜杠（Finder 拖目录的 file-url 带尾 `/`，
  basename 提取会切出空串）
- 格式下拉：**ZIP / TAR.GZ / TAR**（写面三格式——7z/rar 只读是定案，不出现在写选项）
- 级别 0-9（zip）/ gzip 级别（tar.gz）；缺省 6
- 分卷：人读尺寸（100MB/1GB）或介质模板（gmail/cd/dvd…，CLI 契约原样透传）
- 密码：zip AES-256（勾选才出现输入框，密码不落盘不记日志）
- 开始 → 转入**处理台**（同窗口切页，不弹独立窗）

### 1.3 页面二：归档浏览器

### 刻录光盘页（m06038）

侧栏「归档」组第三项（归档浏览入口让位，代码保留）。`zpack burn devices`/`burn <镜像|目录>` 契约驱动：

- **刻录内容清单**（m06212 多输入定案：像压缩台一样任意数量）：文件/文件夹/散件任意混拖；清单卡行（图标+完整路径+hover 浮现移除徽章）+「浏览选择…」多选+「选择文件夹…」单独钮；去重保序。引擎语义：单 .iso 直烧镜像；单目录产 ISO；多输入先聚临时舞台（mac=公共祖先目录硬链接克隆、跨卷回退拷贝；linux=符号链接 -f 跟随）再产 ISO（mac=hdiutil makehybrid -joliet / Linux=xorriso -as mkisofs）；.iso 与其他内容混排拒绝（镜像只能单独刻录）
- **刻录机**：进页懒加载 + 「刷新」钮重枚举；下拉项 = `1 · 厂商 型号（介质态）`（空白/可追加/已满/无介质）
- **写入模式**：可追加（默认，引擎 multi 不封盘——Linux DAO 封死空盘的痛点；m06508 定案由「U盘模式」正名——U盘承诺可删改而多区段做不到）/ 一次性烧录（mastered 封盘最大兼容）；下拉下方独立小字提示随选中+平台变（m06432）：可追加@macOS/Linux=不封盘可继续追加·已写入的内容不能删，@Windows=后续将支持真 UDF 优盘式（可删改），一次性=封盘定稿不可再写·老设备兼容最好
- **刻录速度**：滑杆七档（自动/4/8/16/24/32/48x，m06477 定案替自由输入）——自绘观感同压缩级别滑杆；自动=光驱与碟片协商；真实用途=降速换老设备兼容（车机/老 DVD 机推荐 8x/16x）
- **先擦空再烧**（m06524 定案）：Switch **仅当选中设备的介质可重写（含 RW/RE）时出现**——一次性碟（CD-R/DVD±R）物理不可擦不摆此行；DVD+RW 天生覆盖写免擦不显示；hint 带实际介质名「清空这张 CD-RW 后写入」
- **CTA**：清除 + 刻录（无内容/无刻录机时按钮禁用并说明原因）→ 处理台看进度
- 平台现实：macOS=hdiutil（多驱动器寻址 M2）/ Linux=xorriso（未装报安装引导）/ Windows=IMAPI2 M2（mastered=IDiscFormat2Data，优盘模式=IDiscFormat2RandomWrite）


```
┌────────────────────────────────────────┐
│ ◀ ▶ | 照片合集.zip ▾(路径) | 测试 🧪 信息 ℹ️ │
│ 🔍 [过滤…]                              │
│ ┌────────────────────────────────────┐ │
│ │ 名称            大小   压缩后   类型 │ │  ← 十万级条目虚拟滚动
│ │ 📁 2023-春/      —      —      目录 │ │
│ │ 🖼 a.jpg        4.2MB  3.9MB  JPEG │ │
│ └────────────────────────────────────┘ │
│ 底部：共 1,204 项 · 原始 2.1GB · 压缩 1.4GB · 比 66% · [解压全部] [解压选中] │
└────────────────────────────────────────┘
```

- 打开方式：拖入归档 / ⌘O / 双击（注册关联后缀可选，设置里开关）
- **格式徽章**：读取格式由引擎魔数识别（list 返回 format 字段）——zip/rar/7z/tar 系/iso/cab/wim…读面全格式；徽章旁「只读格式」提示（rar/7z 无压缩入口，只有解压/测试）
- 双击条目 = 预览（M2 先做：提取到临时目录用系统打开；内联预览 M4+）
- 目录树侧栏（可折叠）与平面列表双视图切换
- 加密归档：list 失败提示密码框 → 带 `--password` 重试
- 测试/信息按钮 → 处理台出一条快速任务

### 1.3.5 工具分组：加密 / 解密 / 密钥对 / Base64（2026-11-22 用户两轮定案）

### 1.4 页面三：处理台（多任务并行）

```
┌────────────────────────────────────────┐
│ ▶ 运行中(2)   ✓ 完成(3)   ✗ 失败(0)     │
│ ┌────────────────────────────────────┐ │
│ │ 📦 项目备份.zip                     │ │
│ │ ████████████░░░░░  68.4%           │ │
│ │ 1.2GB/1.8GB · 210MB/s · 3/48 文件 · 剩余 12s │
│ │                    [取消]           │ │
│ ├────────────────────────────────────┤ │
│ │ ✓ 照片合集.zip  2.1GB→1.4GB · 6秒   [打开文件夹] │ │
│ └────────────────────────────────────┘ │
└────────────────────────────────────────┘
```

- 每任务 = 一个 zpack 子进程（引擎天然多进程并行；GUI 不做进程池）
- 进度 = stderr 进度行解析（`压缩中 ██ 68.4% | 1.2GB/1.8GB | …`——与右键进度窗同一套解析器，代码复用）
- 取消 = terminate + 删半成品（compress 契约本来中途失败自删，取消补刀）
- 完成项复用右键进度窗交互规范：**完成后打开文件夹 / 完成后自动关闭**对钩（任务级设置，全局记忆）
- 全部完成且自动关闭勾选 → 收到 Dock 徽章 0 / 可选系统通知

- 通用：缺省格式/级别；默认输出目录（缺省=输入同目录）；`.zpackignore` 说明
- 外观：深浅色跟随/强制；悬浮窗开关与记忆
- 集成：Finder 右键扩展状态检测（pluginkit 查询+跳转系统设置）；文件关联注册（可选）

## 2. 桌面模式

### 2.1 Dock 拖放

- app 为常规 Dock 应用（非 LSUIElement）；拖文件到 Dock 图标 → 系统回调 openFiles → **弹压缩对话**（压缩台参数区浮窗版，同 1.2 的参数与校验）
- 拖归档文件到 Dock → 走打开归档（进主窗口浏览器页）
- ⌘拖到 Dock 图标 = 拷贝文件本体（系统默认行为，不劫持）

### 2.2 桌面悬浮窗（压缩箱）

- 主窗口设置里开关；记忆恢复（launch 时若开过则重建）
- 形态：**120×120 圆角小窗**，可拖动、可吸屏幕边（松手吸附+半藏 40%），置顶可关
- 状态：空态（zpack 图标+「拖入压缩」）/ 拖入悬停（高亮放大）/ 任务中（环形进度+百分比）
- 点击 = 展开迷你任务列表（最近 3 条，运行中优先），再点收起
- 拖入文件 → 直接用**当前缺省参数**压缩（不弹对话——悬浮窗的价值是零摩擦）；按住 ⌥ 拖入 = 弹完整压缩对话
- 输出落点：输入同目录（同名序号保护与右键一致）

## 3. 关键交互流

### 3.1 压缩（主流程）

```
拖入/选择 → 压缩台参数（格式/级别/分卷/密码）→ 开始
  → 处理台新任务（子进程 zpack compress …）
  → stderr 进度 → 进度条；stdout JSON → 结果
  → 完成：对钩动作（打开文件夹/自动关闭）+ Dock 徽章清零
  → 失败：error_info 展示 + 重试按钮（原参数）
```

### 3.2 解压

```
打开归档（list）→ 浏览器 → [解压全部/选中]
  → 缺省智能解压（单根直落/散包包一层）+ 目标选择器
  → 任务（zpack extract）→ 已存在默认跳过（skipped 展示）→ 完成
```

### 3.3 加密归档

```
list 报加密 → 密码框（测试可见性眼睛钮）→ 带 --password 重试 list
→ 成功则记住会话内密码（解压复用；关窗即弃）
```

## 4. 引擎契约映射（GUI 动作 ↔ CLI 命令）

| GUI 动作 | zpack 命令 | 消费字段 |
|---|---|---|
| 打开归档/过滤列表 | `list <归档>` | `format`/`entry_count`/`entries[]`（name/size/compressed/is_dir） |
| 归档信息页 | `info <归档>` | `total_uncompressed`/`archive_size`/`compression_ratio`/`encrypted` |
| 测试 | `test <归档>` | `tested_entries`/`failures[]` |
| 压缩 | `compress <输入...> --output --level [--volume-size] [--password]` | `archive`/`file_count`/`size_bytes` |
| 解压 | `extract <归档> [--output] [--force] [--password]` | `output`/`file_count`/`skipped` |
| 进度（全任务） | stderr 进度行 | `百分比 \| 已处理/总量 \| 速度 \| 文件序 \| 剩余` |
| 校验工具（附赠） | `hash <文件> --algorithm sha256` | `files[].hash`（M4 工具箱页） |
| 随机密码 / UUID | `crypto password --length N [--lower/--upper/--digit/--symbol false]… [--charset <字符集>]` / `crypto uuid [--upper] [--no-dash]` | stdout 纯文本（RunToolText，每行一个） |

GUI v1 完全活在现有契约上（list 的 entries 数组就是浏览器的数据源）；其后仅为 GUI 新增过随机生成页的引擎面 `crypto password/uuid` 与 `--charset`（2026-11-22/23）。

## 5. 技术选型与映射（MyGo）

| GUI 需求 | MyGo 对应 | 风险 |
|---|---|---|
| 十万级条目虚拟滚动 | 列表组件（官方 10 万行基准 2.71ms/帧、可变行高） | 低 |
| 中文 | 系统文本引擎 | 无（egui 字体坑不存在于此路线） |
| 拖放（窗口内 + Dock + 悬浮窗） | 文件拖放 API / app openFiles 事件 | Dock 回调需实测 |
| 多窗口（主窗+悬浮窗） | 多窗口支持 | 悬浮窗吸边动画需自绘 |
| 置顶小窗 | 无边框窗口 + always-on-top | 吸边半藏需自实现 |
| 深浅色 | 主题系统 | 跟随系统需确认 API |
| 分发 | 内置签名/公证/安装包/差量更新 | 低（正是选它的理由） |
| 子进程+管道 | 纯 Go os/exec | 无 |
| 单二进制 | 7-10MB + 内嵌/同目录 zpack 引擎 | 引擎分发：开发态同目录、发布态内嵌 Resources（同 FinderSync 模式） |

**引擎分发定案**：zpack-ui 二进制内嵌 `bin/zpack`（MyGo embed 或 Resources 拷贝，同右键 app 模式）——单文件发布、GUI 与 CLI 版本永不漂移。
